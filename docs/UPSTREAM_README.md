## 第3段階（2026-10-16）
- 手書き入力ベータ：1文字ごとに筆跡を端末内で認識し、12候補から選択して語を組み立てる。1画戻す・書き直し・1文字削除・修正・最終確定・キーボードへの切り替え。筆跡の外部送信と保存なし。書き順や崩し字に精度制約あり。
- 認識器は幾何学的な筆跡テンプレート比較（16点再標本化、全体正規化、画の対応と挿入・削除・隣接交換の距離）。収録地名に使う漢字とかな368文字に対応。現在の問題や正解を候補作成に利用しない。
- 認識データはKanjiVG（© Ulrich Apel and contributors, CC BY-SA 3.0）から抽出・標本化・正規化。派生データ assets/handwriting.json も同じCC BY-SA 3.0。原ライセンスを dist/licenses/ に同梱し、設定に著作権・ライセンス表記。再生成は scripts/build-handwriting.py にKanjiVGのソースディレクトリを渡す。
- プロフィール：名前・12アイコン・解放済み称号を変更。既存のプレイヤーID、記録、保存キーは維持。最大100人・最後の1人の削除防止・ゲスト非保存。
- 記録から判定する7勲章と称号選択。結果画面で新規達成を表示。
- 端末内ランキング：同一の問題プール・条件・回答方法で各人の自己ベストを比較。同点は同順位。90秒モードは回答数で区分せず、同じ時間での正解数を比較。練習・ヒント使用・入力切り替えの記録は対象外。過去版の記録は保持するが、新ランキングには混在させない。
- バックアップ：スキーマ・記録整合性・中断データを検証。読み込み前プレビュー、確定前は元記録を保持、適用直前のスナップショットを保存し戻せる。読み込み不可のローカルデータは別キーにコピーし設定から保存可能。第1・第2段階のv1形式を継続使用。
- PWA：192/512/180px PNGアイコン、Manifest、オフラインの必要資産を一括キャッシュ、準備確認、ホーム画面追加案内、更新待機と利用者による適用。新しいService Workerは自動でプレイ中の版を切り替えない。初回オンライン必須、出典への外部リンクはオンライン専用。OSによるキャッシュ削除後は再準備が必要。

## Safari起動エラー修正（2026-10-16）
ユーザーのSafari画面に `Response served by service worker has redirections`。従来のCache.addAll(index.html)でホストの /index.html → / のリダイレクト履歴を持つResponseを保存し、ナビゲーションへ返していたことが原因と判断。正規の ./ のみをHTMLとして保存し、読める同一オリジンの成功レスポンスをbody/status/headersからnew Responseで再構築。転送履歴を持ち越さず、Location・展開済みContent-Encoding・Content-Length等も除去。キャッシュから返す時も再構築。HTMLのゲーム要素を検証してログインページ等を保存しない。
起動前bootstrapでSWを登録。repair.htmlはSWのナビゲーション横取り対象から外し、このアプリのキャッシュと登録だけを解除する復旧ボタンを用意（localStorageには触れない）。署名ログイン等のプラットフォーム経路も横取りしない。
古いSWがすでに端末のナビゲーションを妨げている利用者向けに、同じ公開プロジェクトのslugを変更し、新しいオリジンからの起動を提供。旧オリジンのブラウザ内設定は新オリジンへ自動移行できないため、ユーザーに名前等の再登録を案内。公開範囲はpublicを維持。一度限りの履歴リセットIDは変更しない。
テストではredirected:trueのレスポンスを模擬し、保存・オフライン配信時にredirected:falseとなること、index.html経由・クエリ付きナビゲーション、復旧・認証経路非横取り、通信失敗時の安全な503ページを確認。Safari実機での確認は未実施。
